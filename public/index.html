WebScreen Flasher ⚡

v1.0

✅ Select Firmware Version:

Choose 4.x for the firmware 4.0 / LVGL 9.5 demo apps. This is a development build.

ℹ️ How to Flash:

  1. Select Version: Choose Stable, Development, or 4.x Development (LVGL 9.5)
  2. Connect Device: Connect your WebScreen device to your computer via USB
  3. Enter Boot Mode: Hold the BOOT button while pressing and releasing the RESET button, then release BOOT
  4. Click Flash: Click the "Connect & Flash WebScreen" button
  5. Select Port: Choose your device from the list in the browser dialog
  6. Wait: The flashing process will begin automatically

Note: This tool requires a Chromium-based browser (Chrome, Edge, Opera) with Web Serial API support.

To save a firmware file without connecting a device, select a version and click Download firmware (.bin). The merged image is intended for flashing at offset 0x0.
